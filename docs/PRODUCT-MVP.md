# DeskFish 产品与 MVP 基线

## 产品定位

DeskFish 是一款 Windows 平台桌面陪伴型鱼缸软件。它需要同时具备“像鱼缸一样自然地持续运行”和“用户可以轻量参与”的特征，视觉目标是优美、舒适，并尽量接近真实鱼缸的观感。

## 已确认的核心方向

- Windows 桌面端为主要产品形态。
- 桌面端使用 Unity 实现。
- 主要内容是鱼缸、鱼群、水草和环境动画。
- 用户可以养鱼、观察成长，并通过鼠标互动。
- 需要提供网页形式的积分排行榜。
- UI、动画和水体表现是产品价值的重要组成部分，而不是后期装饰。

## MVP 必须回答的问题

1. 鱼缸能否作为桌面陪伴窗口稳定运行，并且不妨碍用户正常使用电脑？
2. 鱼只是否有可识别的生命感：游动、转向、停留、受互动影响？
3. 用户是否能理解并完成最小闭环：拥有鱼 → 观察/互动 → 获得成长或积分反馈？
4. 本地状态能否可靠保存并在下次启动恢复？
5. 排行榜是否能展示可解释、可更新的积分结果？

## 当前已完成

- Unity 6.6 项目可打开并完成脚本编译。
- 原型鱼缸场景可进入 Play 模式运行。
- 已验证水体、底砂、水草、气泡、占位鱼和点击波纹的运行时生成。
- 已修复 Game 视图相机视口为零导致的黑屏问题。

## 当前明确不等同于完成

- 当前方块鱼和纯色环境仅为占位表现。
- 当前紫红色背景仅为相机渲染调试色，不是最终透明桌面效果。
- 喂食、成长规则、存档格式、积分规则、账号体系和排行榜服务仍需在后续阶段冻结。

## MVP 验收口径

只有当桌面窗口、核心鱼只行为、本地保存恢复、最小互动反馈和排行榜闭环都可被实际操作验证时，才视为产品 MVP 完成；第一阶段技术验证通过不代表 MVP 已完成。
