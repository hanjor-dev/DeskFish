# 将养成规则与 Unity 表现分离

## 背景

当前技术验证把鱼只行为、场景生成和交互放在 MonoBehaviour 中。正式产品需要支持离线结算、存档迁移、自动测试和未来替换表现资源。

## 决策

鱼只、成长、照料、资源、积分和时间结算属于独立领域层；Unity MonoBehaviour 只负责表现、输入映射和生命周期。应用层通过命令调用领域规则，并以领域事件通知表现和其他适配器。

## 结果

领域规则可以脱离 Unity 做确定性测试和离线结算。表现迭代不会直接改变存档与经济规则。代价是正式功能需要建立接口和状态同步，初期代码量高于继续扩展原型脚本。
