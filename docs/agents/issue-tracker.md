# Issue tracker

This repository tracks work in GitHub Issues.

- Repository: `hanjor-dev/DeskFish`
- Create and update issues with the GitHub CLI or GitHub connector.
- Specs and tickets should use the project's `CONTEXT.md` vocabulary.
- Tickets should receive the `ready-for-agent` label when they are ready for implementation.
- Pull requests are not treated as an incoming request surface for triage.
