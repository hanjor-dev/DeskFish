# DeskFish 产品需求规格

## 1. 产品定位

DeskFish 是 Windows 桌面陪伴型鱼缸。核心价值是让用户在工作、学习或日常使用电脑时，持续看到一个安静、优美、有生命感的鱼缸，并以低负担方式参与照料。

产品优先级依次为：

1. 长时间运行不打扰用户；
2. 鱼只具有可识别的生命感和个体感；
3. 用户能理解并完成轻量养鱼闭环；
4. 本地状态可靠保存；
5. 积分和排行榜可解释、可扩展。

## 2. 目标用户与首发边界

- 首发以个人长期使用和小范围试用为主。
- 平台为 Windows 桌面端，Unity 为客户端运行时。
- 核心体验离线可用，联网排行榜不是 MVP 的前置条件。
- MVP 免费、单机优先，不包含强制账号、云存档、内购和声音。

## 3. MVP 用户旅程

1. 用户首次启动，自动获得三条不同鱼种的鱼只。
2. 鱼缸以透明、无边框、置顶、鼠标穿透窗口运行。
3. 用户可通过快捷键或托盘进入交互模式。
4. 点击水体产生涟漪，并惊扰点击范围附近的鱼只。
5. 点击鱼只打开该鱼的信息卡。
6. 长按水体吸引附近鱼群，松开后鱼群缓慢恢复自然活动。
7. 用户通过喂食完成照料，获得成长、资源和积分反馈。
8. 鱼只从幼体成长为成体，外观和信息卡同步反馈阶段变化。
9. 程序自动保存；重新启动时按离线时间结算并恢复状态。

## 4. 鱼只与内容

### 4.1 鱼只

每条鱼是独立个体，至少包含：唯一标识、鱼种、名称、成长阶段、出生/成长时间、照料统计、可观察状态和表现状态。

鱼只不死亡，不产生不可逆永久损失。成体后不因年龄继续衰退。

### 4.2 鱼种

鱼种定义基础外观、行为倾向、成长表现和食物需求。同一鱼种可以创建多个独立鱼只。

MVP 内容为 3 个初始鱼种和 2 个可解锁鱼种。解锁鱼种后获得鱼种许可，再创建新的鱼只。

### 4.3 数量与性能

鱼只数量没有玩法上的永久硬上限，但受设备性能和观赏质量约束。自动性能档建议容量为：低档 10 条、中档 20 条、高档 40 条。

超出建议容量时允许继续新增，并按以下顺序自动降级：粒子/气泡/焦散、鱼群行为更新频率、鱼只动画质量。

## 5. 照料与资源

- MVP 照料行为只有喂食和互动。
- 喂食先采用按钮投放，拖拽为后续增强。
- 每条鱼按食物份量计算每日推荐量。
- 过量喂食会使鱼短时间变迟钝，并降低当日收益，但不造成永久伤害。
- 养成资源同时用于喂食和鱼种解锁。
- 初始资源应足够喂养三条鱼约 7 天。
- 首个新鱼种目标为启动后 1–3 天内可解锁。
- 有效照料必须受冷却、每日限额或去重规则约束，重复操作不能无限产生成长和积分。

## 6. 时间与收益

- 所有规则使用统一真实时间源。
- 运行期间持续推进；重新启动时按经过时间一次性结算。
- 单次离线最多结算 24 小时。
- 系统时间回拨不产生收益；异常时间差不得破坏存档。
- 有效观赏时间要求窗口可见且未暂停；不可见、暂停和系统休眠不计入。
- 积分来源为有效观赏、有效照料和互动。
- 不提供连续登录/连续使用打卡奖励。
- 积分即时结算，并执行每日上限、冷却和重复事件去重。

## 7. 桌面窗口与 UI

默认窗口为透明、无边框、置顶、鼠标穿透。快捷键和系统托盘均可切换交互模式。

- 鱼只信息卡：点击鱼只打开，展示名称、鱼种、成长阶段、外观进度和可观察状态。
- 全局面板：从托盘进入，提供鱼缸控制、存档、窗口和设置操作。
- 穿透模式下不显示会阻挡桌面操作的 UI。
- 全屏应用不会自动隐藏鱼缸；隐藏/暂停由用户手动控制。
- MVP 默认无声音。

## 8. 存档与隐私

- 使用版本化完整快照保存用户、鱼只、资源、积分、时间和设置。
- 自动保存使用临时文件、校验、原子替换和上一份备份。
- 支持旧版本迁移、合法 JSON 导入导出和明确的重置操作。
- 存档导入仅接受校验通过的产品生成格式及受支持旧版本。
- 本地日志滚动保留，默认不上传；用户可主动导出。

## 9. 排行榜阶段边界

MVP 只提供本地积分和模拟排行榜页面，用于验证积分解释、展示结构和用户理解。

未来联网版本采用匿名身份和可选昵称。客户端保存本地状态，服务端接收可验证事件并计算排行榜积分；客户端不能成为排行榜总分的最终权威。

## 10. 验收标准

### 第一阶段视觉与窗口纵切片

- Windows 独立包支持透明、无边框、置顶、穿透。
- 快捷键和托盘可切换窗口模式。
- 3 条真实风格鱼可连续运行 8 小时。
- 交互模式下点击和长按稳定可用。
- 已建立最小领域规则骨架。

### MVP

- 首次启动、养鱼、互动、喂食、成长、资源反馈形成闭环。
- 自动保存、启动恢复、离线结算和损坏回退可实际验证。
- 本地积分规则可解释并具备限额/去重。
- 模拟排行榜页面可展示本地积分结果。
- 低/中/高建议容量和自动降级策略通过测试。

## 11. 成功验证

先由产品负责人连续使用 3–7 天，再邀请至少 5 名用户试用。记录启动频率、持续运行时长、互动方式、关闭原因、打扰感和鱼只生命感反馈。
